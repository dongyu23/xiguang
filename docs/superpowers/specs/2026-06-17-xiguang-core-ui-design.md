# 隙光核心前端 UI 精修设计

日期：2026-06-17
状态：进行中

## 目标

完成隙光核心前端页面的生产级 UI 精修。优化方向参考 flomo 的快速记录、低打扰回看、流畅切换和克制辅助能力，但保留隙光已有的纸感背景、水纹、手写标题、莫兰迪情绪色、夜间模式和“光片 / 时间河 / 小岛 / 织线”等产品语言。

本轮不修改后端，不改变 API 契约，不新增业务功能。前端需要继续通过现有 provider、repository 和 `ApiClient` 与后端保持连通。

## 范围

覆盖核心闭环页面：

- 登录 / 注册
- 捕光首页
- 时间河
- 光片详情
- 织线
- 小宇宙 / 小岛创建 / 小岛详情
- 我的
- 白噪音
- AI 相关页面

## 设计终点

1. 捕光首页成为真正的首屏记录台：用户打开后无需下拉，就能看到并点击主按钮“捕光”。
2. 页面仍然一眼是隙光：保留手写大字、柔和背景、低饱和情绪色和轻量动效。
3. 信息层级更接近生产级工具：主任务优先，装饰服务于内容，不抢占操作空间。
4. 底部导航与主操作之间保持清楚安全距离，不遮挡按钮或内容。
5. AI 入口保持克制，只作为辅助能力出现，不抢走记录和回看的主线。
6. 所有调整只发生在 Flutter 前端 UI 层，不触碰 Go 后端和接口结构。

## 首页验收标准

在 Android 模拟器 `1080x2280`、debug 包、测试会话下：

- `捕光`按钮完整显示在首屏内。
- 不需要滚动即可点击 `捕光`按钮。
- `捕光`按钮底部与底部导航顶部至少保留 120px 视觉距离。
- 输入框、情绪选择、主按钮共同组成首屏主路径。
- 图片 / 音频入口可以位于主按钮下方，但不得阻挡主按钮。

## 后续调整原则

- 先修核心路径，再修边角状态。
- 每轮修改后构建 Android APK，安装到模拟器截图验证。
- 如果后端服务不可达，可以用本地测试会话验证 UI 壳层；涉及登录、保存、列表数据和 AI 调用的联通验收必须在后端恢复后重新截图确认。
- 不回滚用户已有改动；遇到无关 deleted / modified 文件，只记录，不擅自恢复。
